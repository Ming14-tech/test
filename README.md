# 지하수 관정 지도 — 흐름방향 · 수질기준 판정

관정의 **위치 · 지면표고 · 수위깊이**로 지하수 **흐름방향과 동수구배**를 계산하고,
수질분석 결과를 **「지하수법 시행규칙」[별표 9] 생활용수 수질기준**과 대조해
**[표 7] 오염등급(Ⅰ~Ⅳ)** 을 판정하는 정적 웹 도구입니다.

빌드 도구·서버·데이터베이스가 없습니다. `index.html` 한 장이 전부입니다.

## 쓰는 법

1. 사이트를 엽니다.
2. 좌측 `배경지도` 에서 VWorld 일반/위성 또는 OpenStreetMap 을 고릅니다(인증키는 이미 들어 있습니다).
3. 관정 자료가 이미 들어 있으면 바로 보이고, 다른 자료를 보려면 `관정목록 CSV` 를 올립니다.
4. `수위 CSV` 를 올리면 흐름방향·동수구배·등수위선이 그려집니다.
5. `수질 CSV` 를 올리면 항목별 기준 초과 판정과 등급색이 적용됩니다.
6. `수리전도도 K` 를 넣으면 이동속도·1/5/10년 도달거리까지 계산합니다(비워두면 문헌 범위로 추정).

양식은 `data/samples/` 에 있습니다.

| 파일 | 필수 열 |
|---|---|
| `관정목록.csv` | `지역, 번호, 위도, 경도, 심도` (선택: `주소, 용도, 지면표고`) |
| `수위.csv` | `번호, 수위깊이_GL_m` (선택: `측점표고_m, 측점기준(GL/TOC), 측정일시`) |
| `수질.csv` | `번호, 채수일자, 수소이온농도` + [별표 9] 19개 항목 |

## 계산 방법

수위표고 `h = 표고 − 수위깊이` 를 구해 **최소자승 평면** `h = a·x + b·y + c` 을 맞춘 뒤,
`동수구배 i = √(a²+b²)`, `흐름방향 = atan2(−a, −b)` 으로 산정합니다(3점법의 일반형).
다르시 법칙 `q = −K∇h` 에 따라 흐름은 등수위선에 직교합니다.

배치가 일직선에 가깝거나, 대수층이 섞였거나, 측정일이 다르거나,
평면 잔차가 크거나, 동수구배가 0.001 미만이면 **경고를 함께 표시**합니다.

### 이동속도 · 도달거리

수리전도도 `K` 를 넣으면 다르시 법칙으로 이동속도를 계산합니다.

```
다르시 유속 q = K · i          실제 이동속도 v = q / nₑ        (nₑ: 유효공극률)
```

`K` 를 비워두면 대수층 계열의 **문헌 범위**로 개략 추정합니다
(천부 0.5~50 · 풍화대 0.05~5 · 균열암반 0.005~1 m/일, nₑ 는 0.25 / 0.10 / 0.02).
추정값은 범위가 100배까지 벌어지므로 **현장 양수시험 K** 가 있으면 반드시 그 값을 넣으세요.
단위는 m/일 · cm/초 · m/초 중에서 고를 수 있고, 지도에는 **1년 이동 지점**이 표시됩니다.

## 배포 (Vercel)

```bash
git init && git add . && git commit -m "init"
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

Vercel 에서 **New Project → 이 저장소 Import → Framework Preset: Other** 로 두고 배포하면 됩니다
(빌드 명령·출력 디렉터리 모두 비워 둡니다).

### VWorld 인증키 · 배경지도

- 키는 `data/key.js` 에 들어 있어 **방문자가 입력하지 않아도 지도가 바로 뜹니다.**
  화면 좌측 `배경지도` 에서 **VWorld 일반 / VWorld 위성 / OpenStreetMap** 을 골라 쓸 수 있습니다.
- 배포 후 **VWorld 에 배포 도메인(`<프로젝트>.vercel.app`, 사용자 도메인이 있으면 그것도)을
  반드시 등록**해야 지도 타일이 나옵니다. 등록 전에는 OpenStreetMap 으로 보세요.
- 키를 바꿀 때는 `data/key.js` 의 한 줄만 고치고 다시 배포하면 됩니다.
- 참고: 배포된 파일은 링크를 아는 사람이 열 수 있으므로 **키도 함께 보입니다.**
  키가 새어 곤란해지면 VWorld 에서 폐기하고 새 키를 발급해 같은 파일만 교체하세요.

## 주의

- 이 도구의 표고 기본값은 공개 DEM(SRTM 30 m) 개략치입니다. 정식 산출물에는
  국토지리정보원 5 m DEM 또는 실측 표고를 `측점표고_m` 열에 넣어 쓰세요.
- 수질 판정 기준은 **생활용수** 기준입니다.
- 관정 자료에는 위치정보가 들어갑니다. **소유자 성명·연락처는 절대 올리지 마세요.**
